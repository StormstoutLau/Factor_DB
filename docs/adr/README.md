## 决策记录格式

每个 ADR 文件包含以下章节：
1. **背景** — 需要做决策的原因
2. **决策** — 我们做了什么决定
3. **理由** — 为什么这样做
4. **备选方案** — 考虑过但未采纳的方案
5. **后果** — 决策带来的影响（正面/负面）
